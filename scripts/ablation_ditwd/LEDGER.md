## Which module carries dit_hidden/dit_depth in global mode

`latent_dit`, **not** `trajectory_dit`. `LatentDiT` is constructed unconditionally at
`models/state_hijacking_dit.py:824-832`; in global mode
(`trajectory_mode: false`, `global_denoiser_type: dit`) the trajectory branch falls
through to `else: self.trajectory_dit = None`. Stage-2 freezing selects the same
module (`train_state_hijacking_dit.py:180-182`): `gdt='dit'` and
`trajectory_mode=False` ⇒ `dit_module = model.latent_dit`, so the diffusion loss
flows into the module whose width/depth we are varying.
